# Seedance 2.5 当前写作与任务触发

2026-10-30 核对[火山官方 2.5 提示词指南](https://console.volcengine.com/ark/region%3Acn-beijing/docs/seedance-2-5-prompt-guide)（检索正文显示更新于 2026-10-22）及[官方教程](https://console.volcengine.com/ark/region%3Acn-beijing/docs/seedance-2-5)（更新于 2026-10-28）。本次 docs 镜像仅返回页面壳，详细规则依据 console 原入口可取得的检索正文，不声称镜像全文已读。

正文按素材编号与职责、一句话事件概述、顺序镜头/时间轴、贯穿的场景和声音要求组织。每段描述可见内容、动作、相机与声音，主体和参考编号保持稳定。常见运镜直接写；冷门术语补一句画面变化，转场写清触发点与方式。连贯动作先概括，再细写少数关键动作，不把全段拆成过密微动作。

写作主要用正向描述；字幕、配乐等排除项可直写。台词逐字绑定说话人，情绪和表演另写，避免在台词后反复复述词语而诱发文字。多语言、翻译或替换原音时，逐个标明所有需替换的声源、完整目标台词和保留范围；只参考音色时不顺带继承原对白。

## 官方方舟任务对应关系

以下限本次所读官方方舟文档，第三方入口按其 schema 映射，不照搬键名：

| 任务 | 内容与参数要求 |
| --- | --- |
| 编辑 | 明确“编辑/增加/删除/替换”等动词与源视频；素材 `content.role` 为 `reference_image` / `reference_video` / `reference_audio`；`duration=-1`，按源片时长编辑 |
| 首帧 / 首尾帧 | 用 `first_frame` / `last_frame`；`ratio=adaptive`，首尾画幅尽量一致 |
| 延长 | 写“向前/向后延长、延续、续写”及新情节；参考角色同上，`ratio=adaptive`；时长按当前任务含义核对 |

编辑/延长建议使用 MOV 输入与输出以改善声画衔接，只有当前入口支持时才设置 `output_format`，不为了遵守建议擅自转码或替换原片。编辑输出可能有轻微时长差，不能承诺每帧绝对不变。

素材容量与推荐用量分开：官方指南列视频总时长不超过 30 秒、音频总时长不超过 30 秒；图片/视频/音频数量沿本技能的 30/10/10 发布能力，再核对当前入口。白模用简单几何体表达调度与运动，外观由身份图负责；分镜图少写文字，真实素材顺序与镜头对应明确。

时间轴、局部修改范围与接缝继承读[timeline-edit.md](timeline-edit.md)。只写词可标注参数待核对，不以收费生成来探测功能。
