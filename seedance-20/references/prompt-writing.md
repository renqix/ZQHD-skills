# Seedance 2.0 当前写作要点

2026-10-30 核对[火山官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)；页面另一个语言入口显示更新时间 2026-09-22。以下是本地中文适配，不把结构标题当 API 字段。

先选择任务动词：新片借用素材某一维度写“参考”；直接修改原片写“严格编辑 视频1，将……改为……”；续接原片写“向后延长 视频1……”或“向前延长 视频1……”。编辑/延长的源片不要只写成“参考视频”，以免误成重新创作。组合任务分别说明参考素材和被编辑原片。

素材按上传顺序编号。多份素材中的同一主体绑定到同一名称；不同主体分别命名。用两三个稳定、可见特征消除歧义，后文持续用该名称。Asset ID 不能代替正文的图片/视频编号；示例 `@Image 1` 只是逻辑标签，提交时使用真实入口认可的引用方式。

复杂事件按“镜头1、镜头2……”和因果顺序写主体、位置、动作、运镜与声音。官方提示精确秒点控制仍不稳定，默认优先顺序镜头；用户固定的时间轴仍保留，不承诺逐帧兑现。每镜优先一个主运镜，动作写清方向、速度和衔接，避免相互矛盾。

官方示例区分音乐 `（…）`、音效 `<…>`、台词 `{…}`、字幕 `〖…〗`；按需要采用，不把这些符号当作 API 参数或 H3 的 `<d>`。绑定说话人和语种，逐字保留原台词；未要求字幕时不把对白再描述成屏幕文字。原台词含多语言时保留用户原文并说明各语言归属。

汽车主体沿车辆公共规则；人物人脸参考不能照搬车辆多视图方法。先使用清晰、独立的人脸与全身图，避免把人物多视图宫格误当多个角色。素材取满足控制需求的少量组合，不把容量上限当目标。

编辑与延长的具体镜头写法读[sequence.md](sequence.md)；负面约束只处理本次必要问题，没有独立字段就并入正文。当前素材规格、角色及授权仍由执行入口核验。
