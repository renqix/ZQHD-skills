# 完整创作的阶段参考

这是一组按需使用的创作步骤，不是固定审批或返回验收流程。原片替换沿业务技能，不重复走本页；已有方案、素材和授权直接复用。

| 阶段 | 实际需要完成的事 |
| --- | --- |
| 采意 | 明确给谁看、表达什么、用户已有的内容与素材。 |
| 研究 | 需要外部事实时找依据，复用已有参考与观察，不为凑方向重复检索。 |
| 方案 | 固定内容形式、模型、生成范围及用户例外；已有决定不重复确认。 |
| 脚本 | 把内容落到实际画面、动作、声音及用户原文。 |
| 分镜 | 为需要的镜头写起止状态、运镜和素材分工，不把抽样帧逐张当新镜头。 |
| 素材 | 在原授权内生成或采用现有文件，保存原请求、原文件与来源。 |
| 剪辑 | 执行已约定的拼接、声音、字幕与格式处理，不暗中改变交付形式。 |
| 交付 | 按[统一规则](../../components/workflow/references/return-delivery.md)回传登记，提供真实文件位置与任务状态。 |

业务与模型要求用于创作和提交，返回不按这些要求增设质量判断、评分或重做循环。原请求未完成不冒充已交付；下载或登记中断只续接同一结果。
