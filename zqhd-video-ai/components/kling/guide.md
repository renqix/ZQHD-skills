# Kling 4.0（可灵）提示词规范

核对日期：2026-10-30。官方来源为 Kling 4.0 发布说明与 `klingai-tech/skills`；下列中文写作骨架是本地编排，没有声称存在固定的官方七段或 H3 字段。

## 版本、模式与素材绑定

沿用用户选定的平台、4.0 / 4.0 Flash、时长与声音方案；二者不能仅因同属 4.0 自动互换。版本清楚但参数未查到时可以先写正文，把执行参数标待核对；只写词不要求登录或安装 CLI。

| 输入与目标 | 写作方式 |
| --- | --- |
| 文字创作 | 定义主体和场景，再写事件如何发展、相机如何覆盖 |
| 首帧 / 首尾帧 / 多关键帧 | 明确每帧角色、出现顺序或目标时间，以及相邻帧之间的动作路径 |
| Omni 全能参考 | 分开绑定人物/车辆/物品、场景、动作、运镜、风格与声音 |
| 源视频编辑 / 创意复刻 | 明确直接编辑的原片与借用维度，写出唯一或多个指定变化及保留范围 |

普通参考图不自动成为关键帧；关键帧也不等于切镜命令。主体 Element 只有在实际创建或已存在、且目标模式支持时才能引用。

官方 CLI 的模型清单、槽位、参数与跨类型合计上限由 `who_am_i` 动态提供；只有已选择该通道并需执行时才读取当前帮助。其 Element 使用 `<<<实际 id>>>` 并配套传 `elements`，不是仅在正文写一个昵称。网页、开放平台及第三方入口的 `@Image` / `@Video` / `@Element` 等标记依各自 schema，不把某种语法当成跨平台通用语法，不编造 ID。

## 可复制正文

按“参考与身份 → 整体事件 → 顺序镜头 → 声音 → 保留约束”组织。图生模式省去已由图片固定且无需再次强调的外观，重点写新增动作、运动路径和结尾。新创作可用此本地模板：

```text
整体：已选时长、画幅、单镜或多镜；主体、地点与事件。
参考：逐个列实际绑定素材与职责；身份、表演、运镜和声音分别归属。
镜头 1：构图与景别；主体起始状态；动作的触发、过程和结果；相机方向、速度与终点。
镜头 2：承接上一状态；新变化与转场触发点；最终构图和结束状态。
声音：说话人、语言/方言、语气和“用户台词”；动作声、环境声和配乐。
保持：身份、尺度、位置关系、原片保留内容及用户明确的文字/声音要求。
```

只保留此次实际需要的行。多镜需分清每镜内容和衔接；有已确认时间轴时保留，未要求时不凭空细分大量秒点。主体运动与相机运动分别描述；多角色台词明确谁先谁后、谁开口、谁倾听。画面文字写原文、位置和出现时机，不与台词混为字幕要求。

源片替换沿[公共合同](../workflow/references/subject-replacement.md)保留时间线与原镜头；借用创意结构不自动继承源片的产品、人物或品牌。白模、深度、动作控制等仅在当前 4.0 模式声明支持时采用，不从演示片推断完整接口能力。

## 能力与平台边界

官方发布页列出单次最长 30 秒、最多 15 项混合参考和最多 10 张关键帧，提示词最多 8000 tokens。混合参考另有图/视频/主体子上限，不能把子上限相加当作允许总数；tokens 不等于汉字或字符，实际入口可能更小。菜单中的 `3min` 等数字，未确认含义前不能当作模型输出时长。

发布页对 4K/1080p 的 10-bit HDR、最长 2 分钟扩展保留了 `coming soon` 措辞；未取得当前入口证据时列待核对，不承诺已开放，也不把这些数字套给 Flash。官方发布能力、账号可用模式与实际提交参数分别记录。

交付已选版本/模式、素材绑定清单、完整正文、平台参数与待核对项。负面约束按需写进正文；独立负面字段只在 schema 支持时填写。默认中文、长度与超限处理沿[公共规则](../workflow/references/prompt-authoring-and-limits.md)。汽车任务读[车辆规则](../../references/vehicle-core.md)，返回读[统一交付规则](../workflow/references/return-delivery.md)。技能维护与只写词均不授权生成、安装 CLI、登录或创建持久主体。
