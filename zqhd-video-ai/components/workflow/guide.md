# 完整视频创作编排

仅在用户需要从零策划整条视频时使用。原片主体替换由`zqhd-car-modelvideo`负责；已有素材映射和模式时直接写对应模型提示词，不再展开本流程。

先固定目标、实际素材、交付形式、模型和本次生成范围；已有信息及授权直接沿用，确实缺失且影响执行时集中补齐。复杂任务按[阶段参考](references/stages.md)组织，简单任务只保留需要的步骤，不强制制作一套文档。

1. 明确内容与必要事实，形成可执行脚本或分镜。
2. 按已选模型编写完整提示词，在提交前核对真实接口参数及素材角色；只执行已授权次数。
3. 沿原请求取得文件，完成已约定的剪辑、字幕、原音回填或格式适配。
4. 按[统一返回交付规则](references/return-delivery.md)登记实际文件和回执，不追加质量门。

已有观察、素材及分析按指纹复用；同一规则只由唯一来源维护，不把身份拆解、规划和写词重复做成多轮检查。实际执行由当前可用工具完成，文件缺失或提交未知沿原请求处理。

项目沿用用户目录，记录重要选择、原稿与提交稿、素材顺序、任务回执和交付位置。记录方式见[授权与记录](references/gates.md)；创意方法按需读取[导演参考](references/direction.md)。

生成授权不扩大为充值、公开发布、改变费用或追加版本。交付形式、模型、数量超出原范围时取得对应授权，保持原任务和账务证据。
