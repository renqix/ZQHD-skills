# 返回文件交付规则

这是图片、参考图板及视频返回交付的唯一规则源；主体替换、完整创作及各模型入口共同引用。业务制作要求和提交前限制仍分别由业务技能与实际接口定义。

供应商返回后，沿原任务回执取得原文件，只读取登记和回传所需的元信息。不执行返回内容或质量审查，不比较时长、分辨率、画幅、帧率、主体、字标、比例、声音或同步，不进行整段解码验收、抽帧评分、人工勾选、质量确认或自动修正循环；这些差异不阻断交付。检测状态记录 `skipped / return_checks_disabled`，不伪造检测通过。

文件归属、原请求/轮次、SHA、大小、实际可取得的文件及登记幂等属于回传基础。文件尚未生成、下载中断或登记响应未知时，只查询或续传原文件，不把未完成写成已交付，不重新生成或扣费。

用户选择的时长、清晰度、画幅、帧率用于提交和既有制作适配。已约定的原音回填、格式转换、拼接及尾部处理继续作为制作步骤执行；不在其后增加验收门。上传原素材的官方内容安全检查、真实接口限制及必要输入解码不属于返回检测，不能因此删除。

只有用户明确指出某个问题并要求检查或修正时，独立对照原需求、输入定位、实际提交提示词和原结果取证；这不恢复其它任务的默认检查，也不自动授权新生成、重投或改账。旧模板、旧技能快照、失败原因和模型自报不能重新启用返回检测。
