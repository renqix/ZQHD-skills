# 前期方向：把「感觉」变成可执行的参数

## 一、采意七问（不要一次问完）

1. 目的是什么？（卖车 / 种草 / 告知 / 品牌）
2. 给谁看？（车主 / 潜客 / 泛人群；发在哪个平台）
3. 时长和比例？（15s 9:16？60s 16:9？）
4. 什么感觉？（高级冷峻 / 温暖家庭 / 科技未来 / 运动激情）
5. 有没有参考视频？（有 → 做下面的五要素分析）
6. 看完希望观众做什么、记住什么？
7. 约束：预算上限、必须出现的内容、绝对不要出现的内容

问法：先问最关键的一个（目的/受众），从对话里自然补全；用户已答过的不再问。

## 二、参考视频五要素分析（有参考片时必做）

对每个镜头/镜头组按五个维度拆解，一个都不许省（不适用就写「不适用」，不许沉默跳过）：

1. **主体**：是什么、几个、特征；多主体时怎么区分；跨镜头是否变化
2. **主体动作**：按时间顺序的动作；主体与物体/他人的交互
3. **场景**：叠加层（字幕/标识/图形——单独列出，不算场景本身）+ 视角（航拍/车内/微距/手持…）+ 地点 + 时间 + 动态元素（风、雨、人流）
4. **空间构图**：景别（特写/中景/全景…）+ 主体位置 + 前中后景层次 + 机位相对高度；以及它们在镜头内如何变化
5. **相机**：速度（实时/慢动作/延时）→ 镜头畸变 → 高度 → 角度 → 对焦/景深 → 稳定方式（固定/手持/云台）→ 运动（推/拉/摇/移/环绕）

**关键规则：不要猜参考片是「AI 视频」还是「图片加动效」——看画面运动的连续性再下结论；猜错会导致整条生成路径选错。**

分析结论分三块输出给用户：保留下什么（节奏/结构/钩子）、换掉什么（主题/画面）、按现有工具能做到几成。

## 三、审美三刻度盘（提案阶段锁定）

给每个项目定三个 1–10 的刻度，写进提案：

| 刻度 | 低（1–3） | 中（4–7） | 高（8–10） |
|------|----------|----------|-----------|
| 视觉变化度 | 统一版式反复用 | 有目的的镜头族 | 每个镜头一种视觉语言 |
| 运动强度 | 稳定长镜头 | 明确运镜与转场 | 快切、频繁方向变化 |
| 信息密度 | 一屏一个信息 | 主信息加辅助 | 密集图表/多层信息 |

配一句「设计判词」：不要「现代、简洁、高级」这类形容词堆砌，要具体——例如「车主视角的克制高级感：低饱和、真实材质、无炫技转场」。

**反向检查**：把片名换掉，这条片子还成立吗？成立 = 太泛，回炉。

## 四、提示词五要素公式（写生成提示词时的骨架）

写任何视频生成提示词时，五个槽位必须填满（这是提升出片率最有效的一条）：

```
[主体]      类型 + 关键特征；多主体时怎么区分
[主体动作]  按时间顺序；与物体/他人的交互
[场景]      叠加层单独写 + 视角 + 地点 + 时间 + 动态
[空间]      景别 + 主体位置 + 层次 + 机位高度（及其变化）
[相机]      速度 → 畸变 → 高度 → 角度 → 对焦 → 稳定 → 运动
```

配套规则：

- **叠加层不是场景**：字幕/HUD/水印单独列，不要写「叠加层在前景」
- **推 ≠ 变焦**：dolly 是机位移动，zoom 是焦距变化，写清要哪个；摇 ≠ 移
- **静态镜头是严格定义**：写了「固定机位」就不能有任何运动、变焦或对焦变化
- **长度甜点区**：Seedance 2.0 主打镜头约 200–400 词（英文）等效信息量；短提示词给创意自由，长提示词给控制力

> 与已有技能的关系：本公式是通用骨架；Seedance 具体参数走 `seedance-video`，H3 六段结构走 `minimax-h3-video`——叠加使用，不互相替代。
